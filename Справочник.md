# Общее представление об устройстве камеры
Камера представляет собой arm-компьютер с ОС Linux.  

При включении устройства загружается Linux и стартует дополнительное ПО, которое обеспечивает запись с камеры
либо на SD-карту, либо передачу видио-потока по сети через RTSP-протокол, а также другие предусмотренные
дополнительным ПО функции.
# Как просмотреть файловую систему Linux камеры.
Посмотреть, скопировать файлы файловой системы, выполнить какие-то стандартные команды Linux вы можете через программу telnet, имеющуюся на любом современном ПК или даже смартфоне.  

Изменить какие-то файлы тоже можно через telnet или ftp, но надо понимать что вы изменяете и какие последствия эти изменения могут вызвать. Нодо иметь ввиду, что не все папки в файловой системе Linux доступны для изменения.
# Какой файл запускает ПО камеры?
Специальное ПО камеры V380, как правилоло находится в папке **/mvs/**. Головная программа называется **recorder**. Она запускается командным файлом **/mnt/mtd/nvipcstart.sh**.
# Как запускается web-сервер?
Для того, чтобы web-сервер запускался при включении камеры, соответственно нужно изменить запускной командный файл nvipcstart.sh. Папка, в которой находится этот файл доступна для изменения.  

Установщик, который устанавливает web-сервер изменяет, дописывая в конец запускного файла nvipcstart.sh следующие строки:
```bash
sd=/mnt/sdcard/ark-add-on
if [ -f "$sd/startup.sh" ]; then
	$sd/startup.sh &
fi
```
Эти 4 строки обеспечивают проверку наличия файла **/mnt/sdcard/ark-add-on/startup.sh**, который находится
на sd-карте. Если sd-карта есть и есть файл startup.sh, то он запускается на выполнение.  

Имея такое изменение, вы можете подготовить файл на sd-карте startup.sh с любыми желаемыми командами. В частности с командами запуска web-сервера или ftp-сервера.
