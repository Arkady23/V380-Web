Чтобы создать патч, создайте рядом с java-программой папку с произвольным именем, например mypatch. В этой папке создайте командный файл exshell_bfu.sh с разметкой для файловой системы Linux, в котором поместите требуемые команды. Первой строкой должна быть такая строка:
```bash
#!/bin/sh


```
Также в эту папку, в нашем случае это mypatch, поместите пустые файлы HWNAME.v380_device и 9090909.v380_patchver. Где вместо HWNAME вы должны указать свой вариант hwname.  

Когда файлы для создания патча подготовлены, выполните команду (в нашем случае для папки mypatch):
```bat
pack.bat mypatch
```
